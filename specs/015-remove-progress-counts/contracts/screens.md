# Contrato de telas: Sem contagens nem percentuais de progresso

Antes → depois. Links e destinos não mudam.

| Tela | Antes | Depois |
|---|---|---|
| Início, card da cidade | "7 noites" · "31/10 a 07/11 · 7 dias de roteiro" · "0 de 69 feitas" + barra | "7 noites" · "31/10 a 07/11 · 7 dias de roteiro" |
| Início | "3 destinos" | igual |
| Cidade, cabeçalho | título + anel "0%" | título |
| Cidade, card do dia | tipo + "16 paradas" · "0/4 feitas" + barra | tipo |
| Cidade, card de bairro | foto, data, nome, frase, "Comer (5) Lojas (3) Locações (1)" | foto, data, nome, frase |
| Dia, cabeçalho | título + anel "0%" | título |
| Dia, capa | tipo + "16 paradas" | tipo |
| Dia, linha do tempo | "Opções (8)" | "Opções" |
| Dia, faixa de aviso | "Entendi" · "Ver todos (3)" | "Entendi" · "Ver todos" |
| Dia, seção Dicas | "3 avisos" (recolhido) | "Avisos do dia" (recolhido) |
| Por perto (grupo) | "Comer (6)" "Lojas (5)" "Curiosidades (2)" | "Comer" "Lojas" "Curiosidades" |
| Parada | círculo "Marcar … como feito/pendente" | igual |
| Atração | "Feito" / "Pular" | igual |

## Acessibilidade

- Nenhum `role="progressbar"` em tela nenhuma.
- Nenhum nome acessível com "de N feitas".
- O check mantém o nome "Marcar … como feito" / "… como pendente".
